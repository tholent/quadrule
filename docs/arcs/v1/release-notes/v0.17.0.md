**Pre-alpha.** quadrule is not ready for everyday use yet; files made now may need upgrading later. This release is
polish: a Preferences window with an interface size, a keyboard shortcuts sheet, names for screen readers, quicker
large pages and a round of fixes, approved by chris on 2026-11-26.

## Download

Installers for Linux (AppImage and `.deb`, x86-64 and ARM64), macOS (universal `.dmg`, unsigned) and Windows (`.msi`,
unsigned) are attached below. macOS and Windows will warn that the app is from an unknown developer; `README.md` says
how to open it anyway. Or build from source (`DEVELOPMENT.md`).

On a Mac with Homebrew, `brew install --cask tholent/tap/quadrule` installs the same app as the `.dmg`, once the tap
has been filled in for this release.

## New

- **Preferences** (Ctrl+, or ⌘, on a Mac; File ▸ Preferences…, or the Quadrule menu on a Mac): the interface size from
  75 % to 200 %, or Follow system, and the theme, both remembered. Ctrl +, Ctrl − and Ctrl 0 now zoom the page, not the
  whole window.
- **Keyboard shortcuts** (Help ▸ Keyboard shortcuts): every key on one sheet, made from the same table the menus and
  the window read, so the sheet cannot drift from what the keys do. Shift while drawing a line turns it in 15° steps;
  the font list and the emoji grid take the arrow keys and Enter.
- **Screen readers:** every button, field and tick has a name a screen reader can read, and no two share one.
- **Readable JSON** (Help ▸ Developer ▸ Export as readable JSON…): a page as plain JSON text, for looking inside a
  file. File ▸ Open takes a `.json` back as a new, unsaved page.
- **The inspector's tabs** are one row of icons, with Style before Arrange, the Lint count beside its icon and the
  open tab's name under the row.
- **Clicking a lint finding** picks its object, keeps the Lint tab open and scrolls the page to it.
- **"Mixed" in the Style tab:** with several objects picked, fill, dash, cap and the shape rows read "mixed" when the
  objects differ.

## Faster

- Large pages (A3 or Tabloid at 600 PPI) are drawn at screen size when zoomed out, so an edit or a drag at Fit takes
  about 2 ms a frame instead of over 400 ms. Zooming such a page in toward 1:1 is still slow (about 200 ms a frame); it
  is on the list.
- The largest paper page is now 440 mm a side at 600 PPI (it was 693 mm), which still fits Tabloid and A3. A paper
  profile saved with a larger side is skipped.

## Fixed

- Zooming with Ctrl + scroll no longer jumps up and down: the point under the pointer stays put.
- Choosing "Don't save" and then cancelling Open no longer deletes the crash-recovery file.
- Save records the date the file was last changed, inside the file.
- Paste goes into the layer picked in the layers panel.
- Dragging a selection that holds a locked object says so in the status bar; the locked object stays where it is.

## Files

- The `.quad` format is unchanged at **0.21.0**, and exports are the same bytes as `v0.16.7`.

## What quadrule can do so far (rungs 1–17)

- Open, edit and save `.quad` files; start from a welcome screen with 20 starters, recent files and your own
  templates; export exact-pixel 8-bit gray PNGs for the Supernote Manta (1920 × 2560) and Nomad (1404 × 1872), for
  eleven paper sizes at a chosen PPI, and for screens you describe yourself, from one design, in portrait or
  landscape, named and foldered the way you choose.
- Lines, rectangles, ellipses, polygons and stars (fill, stroke, dashes, caps, rotation, opacity), text boxes with
  bundled and installed fonts, emoji, pattern regions (ruled lines, dots, square grid, isometric, hex, Cornell, music
  staff and grand staff, calendar) with optional borders and rounded corners, major lines counted from where you
  choose, turned whole or with their lines turned inside, and mini calendars; groups and live repeats of any of them.
- A Basic tab with the few settings a template's designer chose to show.
- Pages whose fonts or profiles are missing still open; fonts whose licence allows it, and your own profiles, travel
  inside the file.
- Select, move, resize, marquee, duplicate, copy and paste, align and distribute, layers (made, named and deleted),
  typing on the page, smooth zoom, unlimited undo, autosave and crash recovery; menus on every system, a keyboard
  shortcuts sheet, an interface size, and names for screen readers.
- Snapping to the rhythm, margins, safe zones, the pixel grid, other objects' points and edges, and equal spacing.
- Line roles with values calibrated on real devices and editable in the Profiles window, the safe-zone overlay, a
  linter with eighteen rules and quick fixes, and a check before export.

Source: `v0.17.0`. Earlier rungs are tagged `v0.1.0` to `v0.16.7`.
