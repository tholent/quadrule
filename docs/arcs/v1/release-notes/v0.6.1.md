**Pre-alpha.** quadrule is not ready for everyday use yet; files made now may need upgrading later. This release
marks rung 6b, approved by chris on 2026-11-11.

## Download

Pick the file for your system below (under Assets). `SHA256SUMS.txt` lists each file's checksum.

| System | File |
|---|---|
| macOS (Apple chip or Intel) | `quadrule-0.6.1-macos-universal.dmg` |
| Windows (64-bit) | `quadrule-0.6.1-windows-x86_64.msi` |
| Linux, most PCs | `quadrule-0.6.1-linux-x86_64.AppImage` or `.deb` |
| Linux on ARM (Raspberry Pi 5 and similar) | `quadrule-0.6.1-linux-aarch64.AppImage` or `.deb` |

The macOS and Windows packages are not signed yet, so the system warns the first time you open them. On macOS,
open the app once, then go to System Settings → Privacy & Security and click **Open Anyway**. On Windows, click
**More info**, then **Run anyway**. An AppImage needs to be marked as a program first: `chmod +x` the file, or tick
"Allow executing" in its properties. Only the macOS and Linux ARM packages have been tried so far; reports on the
others are welcome as issues.

## New in rung 6b: rotation, lines any way, opacity

- **Rotation:** select a line or shape and drag the round handle above it. It catches at 0, 90, 180 and 270°; hold
  Shift for 15° steps, Ctrl to turn the catch off. The Arrange tab has a Rotation field in degrees. The selection box
  and its handles turn with the object. Text boxes and pattern regions do not rotate yet.
- **Lines that point any way:** draw a line in any direction, and drag its ends past each other freely.
- **Opacity:** 0–100 % in the Style tab, for every kind of object. The exported PNG stays plain gray: a see-through
  object is flattened over what lies beneath it.
- Turned edges are smoothed; a rectangle or ellipse turned a quarter turn keeps hard, pixel-exact edges.
- File format 0.6.0: files saved by earlier versions open unchanged and export the same pixels.

## What quadrule can do so far (rungs 1–6)

- Open, edit and save `.quad` files; export exact-pixel 8-bit gray PNGs for the Supernote Manta (1920 × 2560) and
  Nomad (1404 × 1872).
- Lines, rectangles, ellipses, polygons and stars (fill, stroke, dashes, caps, rotation, opacity), text boxes, and pattern regions (ruled lines, dots, square grid) bound to the page's rhythm.
- Select, move, resize, marquee, duplicate, copy and paste, layers, unlimited undo, autosave and crash recovery.
- Snapping to the rhythm, margins, safe zones, the pixel grid, other objects' points and edges, and equal spacing.
- Line roles with values calibrated on real devices, the safe-zone overlay, and a linter with seven rules.

Source: `v0.6.1`. Earlier rungs are tagged `v0.1.0` to `v0.6.0`.
