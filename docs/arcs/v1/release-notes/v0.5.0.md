**Pre-alpha.** quadrule is not ready for everyday use yet; files made now may need upgrading later. There are no
installers yet: build from source (see `DEVELOPMENT.md`). This release marks rung 5, approved by chris on 2026-11-10.

## New in rung 5: New and Insert

- **New…** (toolbar button or Ctrl+N, also on the empty screen): pick a device (Manta or Nomad), a rhythm preset
  (handwriting 6 mm, narrow, college or wide ruled, 5 mm grid, 1/4 in grid) and a title. You get a blank template
  whose margins clear the docked Supernote toolbars and footers on both devices.
- **Tools bar** on the left: Select (V), Line (L), Text (T), Pattern (P). Escape ends a tool; double-click a tool to
  keep it on.
- **Drawing:** drag to draw with snapping (sizes land on whole rhythm units), or click for a default size. Each
  drawing is one undo step. A new text box opens the Text tab ready to type.
- The safe-zone lint (L06) no longer checks the floating toolbar, only the docked positions and the footers.

## What quadrule can do so far (rungs 1–5)

- Open, edit and save `.quad` files; export exact-pixel 8-bit gray PNGs for the Supernote Manta (1920 × 2560) and
  Nomad (1404 × 1872).
- Lines, text boxes, and pattern regions (ruled lines, dots, square grid) bound to the page's rhythm.
- Select, move, resize, marquee, duplicate, copy and paste, layers, unlimited undo, autosave and crash recovery.
- Snapping to the rhythm, margins, safe zones, the pixel grid, other objects' points and edges, and equal spacing.
- Line roles with values calibrated on real devices, the safe-zone overlay, and a linter with seven rules.

Source: `v0.5.0` (`9bb8122`). Earlier rungs are tagged `v0.1.0` to `v0.4.1`.
