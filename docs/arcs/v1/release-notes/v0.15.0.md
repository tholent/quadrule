**Pre-alpha.** quadrule is not ready for everyday use yet; files made now may need upgrading later. This release
marks rung 15, export, approved by chris on 2026-11-17.

## Download

Installers for Linux (AppImage and `.deb`, x86-64 and ARM64), macOS (universal `.dmg`, unsigned) and Windows (`.msi`,
unsigned) are attached below. macOS and Windows will warn that the app is from an unknown developer; `README.md` says
how to open it anyway. Or build from source (`DEVELOPMENT.md`).

## New in rung 15: export

- **One Export sheet.** The toolbar's **Export → Export…** (Ctrl+Shift+E; Cmd on a Mac) opens a sheet with the devices
  to export (this one, or all), the folder, the file path, a Set name and a text-note tick. A list under the path shows
  every file that will be written. Every choice is remembered.
- **Export again** (Ctrl+E) writes once more with the last choices and no sheet, for the edit, export, try-on-tablet
  loop. The check before export (rung 14) still runs first when there are warnings.
- **Shorter file names by default:** `{title}-{device}.png`, for example `isometric-5mm-manta.png`. The path is a
  template you can change, with the tokens `{title}`, `{device}`, `{profile}`, `{model}`, `{width}`, `{height}`,
  `{orientation}`, `{type}`, `{date}`, `{version}` and `{set}`. A `/` makes a folder, and a **Presets** menu offers
  three ready-made paths: Flat, Folder per device, and Device then set. Names are kept to letters, digits, hyphens and
  underscores, as Supernote advises, and a path can never leave the folder you chose. If two devices would write the
  same file, the sheet says so in red and holds Export back.
- **Sets for MyStyle:** with the Device then set preset, each device gets a folder that copies straight into that
  tablet's MyStyle folder, so a group of templates stays together in the tablet's template list.
- **A remembered folder** for each document, and the last folder used for a new one.
- **After export**, a sheet shows each file's thumbnail, where they went, how many files were replaced, **Reveal in
  folder**, and a folded **Where do these go?** note about the MyStyle folder.
- **A text note in each PNG** (on by default; a tick turns it off): the app and its version, and the document's title,
  in PNG's own Software and Title fields. The pixels are unchanged, and a noted page works as a template on the Nomad.

## Files

- Files are saved as format **0.16.0**: a `.quad` now carries a small picture of its page (the main device, 480 px on
  its longest side) for the coming welcome screen. Every older file opens with the same exported pixels and gets its
  picture at its next save.
- Your export choices are kept in a `settings.ron` in the app's config folder, never in the `.quad`.

## What quadrule can do so far (rungs 1–15)

- Open, edit and save `.quad` files; export exact-pixel 8-bit gray PNGs for the Supernote Manta (1920 × 2560) and
  Nomad (1404 × 1872), for eleven paper sizes at a chosen PPI, and for screens you describe yourself, from one design,
  in portrait or landscape, named and foldered the way you choose.
- Lines, rectangles, ellipses, polygons and stars (fill, stroke, dashes, caps, rotation, opacity), text boxes with
  bundled and installed fonts, emoji, and pattern regions (ruled lines, dots, square grid, isometric, hex, Cornell,
  music staff), turned whole or with their lines turned inside; groups and live repeats of any of them.
- Pages whose fonts or profiles are missing still open; fonts whose licence allows it, and your own profiles, travel
  inside the file.
- Select, move, resize, marquee, duplicate, copy and paste, align and distribute, layers, typing on the page,
  unlimited undo, autosave and crash recovery.
- Snapping to the rhythm, margins, safe zones, the pixel grid, other objects' points and edges, and equal spacing.
- Line roles with values calibrated on real devices and editable in the Profiles window, the safe-zone overlay, a
  linter with eighteen rules and quick fixes, and a check before export.

Source: `v0.15.0`. Earlier rungs are tagged `v0.1.0` to `v0.14.0`.
